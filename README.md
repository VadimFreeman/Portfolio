# Vadim Freeman — Portfolio

Персональный сайт-портфолио на чистых HTML, CSS и JavaScript. Не требует сборки или установки зависимостей.

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Что поменять в первую очередь

- `index.html`: тексты, проекты, email и ссылки на соцсети.
- `style.css`: цвета в начале файла (`:root`), размеры, отступы и оформление.
- `script.js`: поведение мобильного меню.

Найдите `hello@example.com` и замените на свой email. Карточки проектов сейчас демонстрационные — обновите названия, описания и содержимое в секции `#work`.

## Публикация через GitHub Pages

Создайте репозиторий `Portfolio`, загрузите файлы в ветку `main`, затем откройте Settings → Pages и выберите Deploy from a branch → `main` → `/ (root)`.
